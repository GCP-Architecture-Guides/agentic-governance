# Observability Matrix

This document outlines the observability signals captured for the Secure Agentic Perimeter.

| Signal | Source | Attributes Captured |
| :--- | :--- | :--- |
| **GenAI Spans** | `google-genai` | Token usage, model version, and response latency |
| **Egress Hops** | `httpx` | Proxy URL (`10.10.10.5:8888`), destination domain, and status codes |
| **Ingress Flow** | `fastapi` | Request path, IAP identity headers, and processing time |

## Operational Validation

### Verifying Spans in Cloud Trace

Once the agent is redeployed and traffic is generated, you can verify the telemetry in the Cloud Trace console:

1.  **GenAI Spans**:
    *   Search for spans with attributes related to `google-genai`.
    *   Confirm that `token usage`, `model version`, and `latency` are captured.

2.  **Egress Hops**:
    *   Look for spans generated by `httpx` when the agent makes outbound calls (e.g., via the `make_http_request` tool).
    *   Verify that the `Proxy URL` attribute shows `10.10.10.5:8888` (or the configured proxy) and that the destination domain and status codes are correct.
    *   This confirms that the outbound tool call was successfully intercepted and logged by the `httpx` instrumentor before hitting the Secure Web Proxy (SWP).

3.  **Ingress Flow**:
    *   Look for spans from `fastapi` representing the incoming requests to the agent.
    *   Check for `Request path` and `IAP identity headers` to trace the flow from the Ingress Gateway.
